# Pet Weight & Calorie Calculator

🚧 Work in progress

## Purpose
Lightweight desktop program. Inputs pet's species (dog or cat) and current
body condition score (out of 9), then calculates and outputs recommended
healthy weight and daily calorie range to achieve and maintain that weight.

## Tech Stack
Python, customtkinter (GUI), PyInstaller (packaging)
